# Autoencyclopedia

A web application for browsing vehicle information, finding cars, buying and selling in a marketplace, and using an AI car helper.

NOTICE: This project and its source code are private and strictly protected. Unauthorized copying, distribution, modification, or commercial use is strictly prohibited.

## Live Application

The application is live and accessible at: https://autoency.byst.re

## Features

### 1. Vehicle Information
- Browse cars, motorcycles, and boats.
- View vehicle details, specifications, common issues, and engine information.

### 2. Saved Vehicles
- Logged-in users can save vehicles to their favorites list.
- Free accounts can save up to 4 vehicles.
- PRO accounts can save an unlimited number of vehicles and compare them side by side.

### 3. Marketplace and VIP Area
- Users can post cars for sale with photos, price, location, and phone number.
- Admin approves listings before they are published.
- Search and filter listings by brand, model, price, and location.
- VIP Lounge: A special section for cars priced over 300,000, available only for PRO users.

### 4. AI Car Advisor
- An AI chatbot that helps users choose the right car.
- Free accounts get 3 questions per day.
- PRO accounts get unlimited access.

### 5. PRO Subscription
- Monthly and yearly payment options using Stripe.
- Supports multiple currencies.
- Users keep their access until their paid period ends, even if they cancel auto-renewal.

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend and Database: Supabase (PostgreSQL)
- Payments: Stripe
